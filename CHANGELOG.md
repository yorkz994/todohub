## 0.1.0 — 2026-11-18

First public release.

- Event-sourced store and `hub` CLI; areas → projects → threads with `goal` / `state` / `next`.
- Local daemon: dashboard, Codex / Claude Code session collectors, Reminders two-way sync, repo screener, weekly review, task runner with daily cap, timeout, pause and review mode.
- Claude orchestrator playbook (`CLAUDE.md`) and agent notes (`AGENTS.md`).
- Native macOS menu-bar app and floating panel (Objective-C, built locally with clang).
- Personal settings in git-ignored `.local` files; privacy audit of files and full commit history before every publish and in CI.
- `scripts/demo.py`: try the dashboard with fictional data; `hub --version`.
- Docs: architecture, scheduling, contributing, security policy, code of conduct.
